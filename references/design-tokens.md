# 统一视觉规范

在方向选定后使用。为本次任务生成具体值并映射到项目变量；没有适合所有业务的默认配色、字体或圆角。

## 生成方法

先检查已有设计系统。保留适合的语义、变量和组件；确需改变时限定在本页面范围并说明。把参考方法转为角色值，避免每个区块保留各自参考的参数。所有值都用真实内容校准，再用于实现。

| 类别 | 本次必须产出的值／规则 |
| --- | --- |
| 颜色角色 | canvas、surface、text-primary、text-secondary、accent、on-accent、border；需要交互时补 focus、错误／成功状态。为实际相邻组合检查对比度，不能仅看色板 |
| 字体角色 | 标题、正文、辅助、按钮的字体栈、字号、字重、行高、字距；中文字体及可用回退。明确桌面与手机变化，避免英文字体缺中文字形造成混乱 |
| 间距尺度 | 小到大的离散间距值；组件内、内容组、模块间分别映射。只对有理由的特殊构图例外 |
| 布局 | 最大内容宽度、各视口边距、列数、栏间距、文字行宽和图像比例；按内容折叠，说明 1440／768／390px 的结果 |
| 组件形态 | 按钮、卡片、输入等所需组件的圆角、边框、阴影、内边距、图标尺寸；同角色一致 |
| 动效 | 必要效果的目的、触发、时长、缓动、可中断性与 reduced-motion；无需动效时明确为静态，不为补齐表格添加动画 |

方案模式也要给具体值，例如实际色值、字号、行高与边距，而不是只交付“清爽”“高级”。实现模式输出 CSS custom properties 或现有栈等价 tokens，并让组件引用它们。

## 内容校准

- 用用户最长的实际标题和段落测试换行；中文不强套英文大字距、全大写或固定一行。标题需要合理的断行与宽度，不能靠整体缩小到难读来修复。
- 图像采用实际可用数量和比例，定义裁切焦点与替代文本。若素材不足，改变构图和信息承载方式；图框不应等待不存在的素材才成立。
- 使用流式尺寸和必要断点适配内容，不固定整页高度或按屏幕缩放全部元素。平板不是简单压缩桌面；手机明确导航、阅读顺序、按钮与图像的去向。
- 正文对比度至少 4.5:1，大字至少 3:1（至少 24 CSS px 常规或约 18.7px 粗体）；必要控件边界与焦点等非文本信息至少 3:1。不要用颜色单独表达状态。若无法计算则列未验证。
- 避免为不同模块新增独立字体、阴影和圆角。只有具有明确语义的例外才可扩展 tokens，并检查整页一致性。
