# 参考分析模板

在观察参考时使用。每份可读参考一条记录；不适用也要分析，之后再舍弃。模板是工作记录，不要求原样交给用户。

## 证据清单

| 字段 | 记录方式 |
| --- | --- |
| 编号与来源 | R编号、文件／网址、截图尺寸、录屏时间点；合成材料明确标记 |
| 可读性 | 可读／部分可读／不可读，实际观察范围与失败原因 |
| 页面用途与气质 | 已知业务；用可见设计关系说明气质，不堆砌形容词 |
| 证据定位 | 画面区域／滚动位置／帧时间点；需要时保存截图位置 |

视觉分析必须看画面。网址无法渲染时，可读取文本帮助理解业务，但视觉分析仍标不可读。长截图只证明捕获范围；截图裁切不证明真实容器边界。图片中的字体、颜色、尺寸若不能准确辨认，记录估计或范围，不冒充 CSS 取值。录屏没出现的 hover、滚动阶段、手机布局和转场都保持未知。

## 每份参考的分析表

每行填“观察事实＋依据”“设计推断＋置信度／待验证”“可迁移关系”。不适用或无法观察写原因，不用虚构内容补齐表格。

| 维度 | 要记录的关系 |
| --- | --- |
| 层级与阅读 | 主标题／正文／CTA／图像的先后、对比强度、主要视觉中心，如何支持任务 |
| 栅格与比例 | 列数、对齐线、内容宽度、文字与图片占比；区分可测尺寸和视觉估计 |
| 字体 | 标题／正文／辅助文字的角色，字号级差、字重、行高、字距；中文字形是否实际出现 |
| 颜色 | 背景、文字、强调色的角色及大致面积；局部对比如何引导关注 |
| 留白与节奏 | 行内、组件内、模块间距离；密度变化、分组、滚动节奏的可见依据 |
| 图像 | 主体位置、构图、裁切、比例、背景关系；插图／产品展示如何解释内容 |
| 组件 | 圆角、边框、阴影、尺寸、图标描边／填充风格；哪些共用规则 |
| 交互与动效 | 实际观察的触发、反馈、持续时间估计；不可见行为列未知 |

将含糊评价改写为可执行关系，例如：“左侧约四成宽度的标题与右侧产品图共用底部对齐线，主按钮位于摘要之后；读者先理解用途，再看到证据并行动”。再判断这套关系能否容纳用户的中文长标题，而不是直接抄取这份比例。

## 跨参考摘要

列共同规律、显著冲突、可迁移方法、不可使用的品牌资产，以及未知项。把“参考看起来适用”与“已用实际内容验证适用”分开。未知项可以通过合理设计决策补足，但不得归因于参考。
