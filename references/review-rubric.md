# 验收与有限自修正

在交付前使用。先检查严重问题，再判断质量；不能用平均分掩盖失败。此标准用于一次任务的自检，不等于正式试用认证。

## 验证证据

实现时记录启动／构建命令与结果、实际访问位置、视口宽度、截图文件、操作检查和问题状态。能渲染时实际查看 1440、768、390 CSS px 的页面，长页检查首屏及下方全部主要模块，不能只看首屏或 DOM。截图证明布局，操作需另行执行。缺少工具或项目不可运行时列具体未验证项。

方案交付可检查内容结构、tokens、响应式规则与状态定义；未实现的页面、真实断点、交互、字体加载和视觉结果均不能宣布已验证。

## 严重问题：有任一项则不能宣布验收通过

- 页面无法打开、关键资源缺失导致主体内容不可用。
- 390px 发生妨碍阅读／操作的横向溢出、重叠或核心内容消失；不要通过全局裁切隐藏缺陷。
- 主要文字难读、对比不足或字号过小；核心内容被强制截断。
- 遗漏核心需求、主要操作不可达，或把演示反馈假装成真实提交。需要服务但尚未接入时明确交付边界。
- 直接复刻参考的鲜明整套构图或违规取用参考资产。

## 质量检查

| 维度 | 可观察的通过依据 |
| --- | --- |
| 一致性 | 相同角色共享字体、色彩、间距、组件规则；特殊处理有明确用途 |
| 信息层级 | 第一视觉中心支持目标；真实长文案仍有阅读顺序，主操作清楚 |
| 需求适配 | 必要内容齐全，图像与证明材料真实，页面结构符合业务目标 |
| 辨识度 | 整体表达和任一参考有实质区别；不是通用模板或参考区块拼接 |
| 响应式质量 | 三个视口均检查对齐、换行、裁切、溢出和节奏；手机任务可完成 |
| 可用性与无障碍 | 语义结构合理，键盘可操作、焦点可见，必要的 hover／focus／active／错误等状态明确；有意义的图片有替代文本，装饰不干扰读屏；点击目标易触达，动效尊重 reduced-motion |

只检查页面实际需要的状态，不凭空引入表单或菜单。主要操作应指向有效目标；本地演示受限时可清楚标记模拟行为，不得误导为已发送或已预约。基础无障碍检查不等于完整合规认证。

## 自修正与停止

先修严重问题，再修层级／一致性，最后处理装饰。每次针对观察到的问题调整，复查受影响视口及关键操作。可修的严重问题继续处理；同一修改没有改善时先诊断原因，不盲目重试。无新增证据时停止随机换风格，验收满足后停止无必要的迭代。确有工具、资源或运行能力阻碍时列出问题、影响和未验证项，不宣称成功。用户追加需求可继续处理。

简短交付记录：最终方向与参考取舍、结果位置、运行方式、已执行的验证和未验证项。完整分析留在工作记录，不要求用户读设计论文。合成烟测只能验证有限行为；真实参考泛化、人工偏好和正式三十次试用必须另外记录。
